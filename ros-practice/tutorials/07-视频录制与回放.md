# 07 视频录制与网页展示

## 7.1 录制方案概述

| 方案 | 工具 | 适用场景 | 输出格式 |
|------|------|---------|---------|
| Gazebo 内置录制 | `gz sim --record` | 仿真过程录制 | MP4 |
| ROS2 bag 录制 | `ros2 bag record` | 话题数据录制 | MCAP |
| 屏幕录制 | ffmpeg / OBS | RViz + Gazebo 全屏 | MP4 |
| RViz 录制 | ros2 run rviz2 | RViz 动画 | PNG 序列 |

## 7.2 方案一：Gazebo 内置录制

```bash
# 启动 Gazebo 时开启录制
gz sim -r --record --record-path ~/videos warehouse.sdf

# 录制完成后，文件保存为
# ~/videos/gazebo_record_YYYYMMDD_HHMMSS.mp4
```

## 7.3 方案二：屏幕录制脚本（推荐）

### record_video.sh — 完整录制脚本

```bash
#!/bin/bash
# 录制 Gazebo + RViz 仿真过程
# 用法: ./record_video.sh [时长秒数] [输出文件名]

DURATION=${1:-60}
OUTPUT=${2:-ros_sim_$(date +%Y%m%d_%H%M%S)}
OUTPUT_DIR=~/ros_practice_videos
mkdir -p $OUTPUT_DIR

echo "========================================"
echo "  ROS2 仿真视频录制脚本"
echo "  时长: ${DURATION}秒"
echo "  输出: ${OUTPUT_DIR}/${OUTPUT}.mp4"
echo "========================================"

# 获取屏幕分辨率
RESOLUTION=$(xdpyinfo | grep dimensions | awk '{print $2}')
echo "屏幕分辨率: $RESOLUTION"

# 检查 ffmpeg 是否安装
if ! command -v ffmpeg &> /dev/null; then
    echo "安装 ffmpeg..."
    sudo apt install -y ffmpeg
fi

# 开始录制
echo "[$(date +%H:%M:%S)] 开始录制..."
echo "请在 ${DURATION} 秒内操作仿真"

ffmpeg -y \
    -f x11grab \
    -framerate 30 \
    -video_size $RESOLUTION \
    -i :0.0 \
    -c:v libx264 \
    -preset fast \
    -crf 23 \
    -t $DURATION \
    ${OUTPUT_DIR}/${OUTPUT}.mp4

echo "[$(date +%H:%M:%S)] 录制完成！"
echo "文件: ${OUTPUT_DIR}/${OUTPUT}.mp4"
echo "大小: $(du -h ${OUTPUT_DIR}/${OUTPUT}.mp4 | awk '{print $1}')"

# 生成缩略图
ffmpeg -y -i ${OUTPUT_DIR}/${OUTPUT}.mp4 \
    -ss 00:00:05 -frames:v 1 \
    ${OUTPUT_DIR}/${OUTPUT}_thumb.png

echo "缩略图: ${OUTPUT_DIR}/${OUTPUT}_thumb.png"
```

## 7.4 方案三：自动建图录制脚本

### record_slam_mapping.sh — SLAM 建图全自动录制

```bash
#!/bin/bash
# 自动录制 SLAM 建图全过程
# 用法: ./record_slam_mapping.sh

source /opt/ros/jazzy/setup.bash
source ~/ros2_ws/install/setup.bash

OUTPUT_DIR=~/ros_practice_videos
mkdir -p $OUTPUT_DIR
TIMESTAMP=$(date +%Y%m%d_%H%M%S)

echo "===== SLAM 建图录制 ====="

# 终端1：启动仿真（后台）
gnome-terminal -- bash -c "
  source /opt/ros/jazzy/setup.bash
  source ~/ros2_ws/install/setup.bash
  ros2 launch myfirst_robot gz_sim.launch.py
  exec bash
" &
sleep 5

# 终端2：启动 SLAM（后台）
gnome-terminal -- bash -c "
  source /opt/ros/jazzy/setup.bash
  source ~/ros2_ws/install/setup.bash
  ros2 launch myfirst_robot slam.launch.py
  exec bash
" &
sleep 3

# 终端3：启动键盘遥控（后台）
gnome-terminal -- bash -c "
  source /opt/ros/jazzy/setup.bash
  source ~/ros2_ws/install/setup.bash
  ros2 run myfirst_robot teleop_keyboard
  exec bash
" &
sleep 2

# 开始屏幕录制（120秒）
echo "开始录制 120 秒..."
RESOLUTION=$(xdpyinfo | grep dimensions | awk '{print $2}')
ffmpeg -y \
    -f x11grab \
    -framerate 30 \
    -video_size $RESOLUTION \
    -i :0.0 \
    -c:v libx264 \
    -preset fast \
    -crf 23 \
    -t 120 \
    ${OUTPUT_DIR}/slam_mapping_${TIMESTAMP}.mp4

echo "录制完成: ${OUTPUT_DIR}/slam_mapping_${TIMESTAMP}.mp4"

# 保存地图
echo "保存地图..."
mkdir -p ~/maps
ros2 run nav2_map_server map_saver_cli -f ~/maps/warehouse_${TIMESTAMP}

echo "===== 全部完成 ====="
echo "视频: ${OUTPUT_DIR}/slam_mapping_${TIMESTAMP}.mp4"
echo "地图: ~/maps/warehouse_${TIMESTAMP}.pgm"
```

## 7.5 方案四：自动导航录制

### record_navigation.sh — Nav2 导航录制

```bash
#!/bin/bash
# 自动录制 Nav2 导航过程
# 用法: ./record_navigation.sh

source /opt/ros/jazzy/setup.bash
source ~/ros2_ws/install/setup.bash

OUTPUT_DIR=~/ros_practice_videos
mkdir -p $OUTPUT_DIR
TIMESTAMP=$(date +%Y%m%d_%H%M%S)

# 启动仿真
gnome-terminal -- bash -c "
  source /opt/ros/jazzy/setup.bash
  source ~/ros2_ws/install/setup.bash
  ros2 launch myfirst_robot gz_sim.launch.py
  exec bash
" &
sleep 5

# 启动导航
gnome-terminal -- bash -c "
  source /opt/ros/jazzy/setup.bash
  source ~/ros2_ws/install/setup.bash
  ros2 launch myfirst_robot nav2_bringup.launch.py map:=~/maps/warehouse.yaml
  exec bash
" &
sleep 5

# 发送导航目标（自动）
echo "发送导航目标..."
ros2 action send_goal /navigate_to_pose nav2_msgs/action/NavigateToPose \
  "{pose: {header: {frame_id: map}, pose: {position: {x: 3.0, y: 0.0, z: 0.0},
   orientation: {w: 1.0}}}}" &

# 录制 60 秒
RESOLUTION=$(xdpyinfo | grep dimensions | awk '{print $2}')
ffmpeg -y -f x11grab -framerate 30 -video_size $RESOLUTION -i :0.0 \
    -c:v libx264 -preset fast -crf 23 -t 60 \
    ${OUTPUT_DIR}/navigation_${TIMESTAMP}.mp4

echo "录制完成: ${OUTPUT_DIR}/navigation_${TIMESTAMP}.mp4"
```

### 启动本地视频服务器

```bash
# 进入 web 目录
cd ~/ros2_ws/src/myfirst_robot/web

# 方式1：Python HTTP 服务器
python3 -m http.server 8080

# 方式2：Node.js（如已安装）
npx http-server -p 8080

# 浏览器访问
xdg-open http://localhost:8080
```

## 7.7 视频压缩与格式转换

```bash
# 压缩视频（减小文件大小）
ffmpeg -i input.mp4 -c:v libx264 -crf 28 -preset slow output_compressed.mp4

# 转换为 GIF（用于文档展示）
ffmpeg -i input.mp4 -vf "fps=10,scale=640:-1" output.gif

# 提取关键帧
ffmpeg -i input.mp4 -vf "select=eq(n\,0)+eq(n\,300)+eq(n\,600)" -vsync vfr frames_%03d.png

# 合并多段视频
ffmpeg -f concat -i filelist.txt -c copy merged.mp4
# filelist.txt 内容:
# file 'part1.mp4'
# file 'part2.mp4'
```
