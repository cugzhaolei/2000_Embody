# 06 Nav2 导航实战

## 6.1 Nav2 架构概览

```
                    ┌──────────────────────────────────┐
                    │         BT Navigator             │
                    │  (行为树编排导航流程)               │
                    └───┬──────┬──────┬──────┬─────────┘
                        │      │      │      │
                 ┌──────┴──┐┌──┴────┐┌─┴────┐┌┴──────────┐
                 │Planner  ││Ctrl  ││Behavior││  Goal    │
                 │Server   ││Server││Server  ││  Pose    │
                 │(全局规划)││(局部) ││(恢复)  ││  Plugin  │
                 └────┬────┘└──┬───┘└───┬───┘└──────────┘
                      │        │        │
                 ┌────┴────┐┌──┴─────┐┌──┴──────┐
                 │Navfn   ││DWB    ││Spin     │
                 │Planner ││Local  ││BackUp   │
                 │(A*/Dijkstra)│Planner││Wait    │
                 └────────┘└───────┘└─────────┘
```

### Nav2 核心组件

| 组件 | 功能 | 默认插件 |
|------|------|---------|
| bt_navigator | 行为树编排导航流程 | NavigateToPose |
| planner_server | 全局路径规划 | NavfnPlanner (A*) |
| controller_server | 局部路径跟踪 | DWBLocalPlanner |
| behavior_server | 异常恢复行为 | Spin/BackUp/Wait |
| amcl | 自适应蒙特卡洛定位 | AMCL |
| map_server | 加载静态地图 | map_server |
| lifecycle_manager | 管理节点生命周期 | lifecycle_manager |

## 6.3 启动导航

```bash
# 终端1：Gazebo 仿真
ros2 launch myfirst_robot gz_sim.launch.py

# 终端2：Nav2 导航
ros2 launch myfirst_robot nav2_bringup.launch.py map:=~/maps/warehouse.yaml

# 终端3：发送导航目标
ros2 action send_goal /navigate_to_pose nav2_msgs/action/NavigateToPose \
  "{pose: {header: {frame_id: map}, pose: {position: {x: 3.0, y: 0.0, z: 0.0},
   orientation: {w: 1.0}}}}"
```

## 6.4 RViz 交互导航

### RViz 工具栏使用

1. 点击 **"2D Goal Pose"** 按钮
2. 在地图上点击目标位置
3. 拖拽设定朝向

## 6.5 导航调试指南

### 常见问题排查表

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 机器人原地旋转 | AMCL 定位丢失 | 重置初始位姿 |
| 规划路径穿墙 | 代价地图未更新 | 检查 /scan 数据流 |
| 到目标点不停 | goal_tolerance 过小 | 增大 xy_goal_tolerance |
| 导航卡住 | 恢复行为触发 | 观察 BT 状态 |
| 抖动振荡 | 控制增益过高 | 调低 max_vel_theta |

### AMCL 初始位姿设置

```bash
# 方法1：命令行设置初始位姿
ros2 topic pub --once /initialpose geometry_msgs/PoseWithCovarianceStamped \
  "{header: {frame_id: map}, pose: {pose: {position: {x: 0.0, y: 0.0, z: 0.0},
   orientation: {w: 1.0}}}}"

# 方法2：RViz "2D Pose Estimate" 按钮
# 在 RViz 中点击地图上机器人实际位置
```

### 定位质量评估

```bash
# 查看粒子分布收敛情况
ros2 topic echo /particle_cloud --once
# particles 数量应在 500-2000 之间
# 协方差应 < 0.1（收敛良好）

# 查看定位频率
ros2 topic hz /amcl_pose
# 应为 5-10 Hz
```

## 6.6 导航性能优化

### 速度参数调优

```python
# 差速驱动机器人速度限制
max_vel_x = 0.7      # 线速度（考虑安全）
max_vel_theta = 1.0   # 角速度
acc_lim_x = 2.5       # 加速度（避免打滑）
acc_lim_theta = 3.2    # 角加速度

# 安全速度（有人环境）
safe_vel_x = 0.3      # 降低到 0.3 m/s
safe_vel_theta = 0.5   # 降低到 0.5 rad/s
```

### 代价地图膨胀半径

```python
# 膨胀半径应 > 机器人外接圆
robot_radius = 0.35    # 机器人最大对角尺寸
inflation_radius = 0.55  # 膨胀半径 = robot_radius + 0.2m 安全裕度
```
