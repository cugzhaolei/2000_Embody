# 02 机器人模型搭建：SDF 差速驱动机器人

## 2.1 SDF vs URDF 对比

| 特性 | URDF | SDF |
|------|------|-----|
| 文件格式 | XML | XML（schema 更丰富） |
| 支持 Gazebo | 需转换 | 原生支持 |
| 多机器人 | 不支持 | 支持 `<model>` 嵌套 |
| 传感器定义 | 需 Gazebo 标签 | 原生 `<sensor>` 标签 |
| 环境建模 | 不支持 | 支持 `<world>` |
| ROS2 TF | 原生支持 | 需 `ros_gz` 桥接 |

> 本项目直接使用 SDF 格式，避免 URDF→SDF 转换中的信息丢失。

## 2.2 机器人结构设计

```
                    laser_link (360° LiDAR)
                        |
                  laser_cylinder_link
                        |
        left_wheel -- base_link -- right_wheel
                        |
                   caster_wheel (万向轮)
```

## 2.4 关键参数解析

### 差速驱动运动学

```python
# 差速驱动正运动学
# v = (v_L + v_R) / 2        线速度
# ω = (v_R - v_L) / L        角速度（L=轮距）
# L = 0.4m（wheel_separation）
# r = 0.133m（wheel_radius）

# 关节角速度 → 线速度
# v_L = ω_L × r
# v_R = ω_R × r

# 示例：原地旋转
# v_L = -0.5 m/s, v_R = +0.5 m/s
# v = 0 m/s, ω = (0.5-(-0.5))/0.4 = 2.5 rad/s
# 旋转一周耗时 = 2π / 2.5 = 2.51 秒
```

### 激光雷达参数

| 参数 | 值 | 说明 |
|------|-----|------|
| samples | 360 | 水平采样数，角分辨率 1° |
| min_angle | 0 rad | 起始角度 |
| max_angle | 2π rad | 终止角度（360°全覆盖） |
| range_min | 0.01 m | 最小量程 |
| range_max | 20.0 m | 最大量程 |
| update_rate | 5 Hz | 更新频率 |
| noise | Gaussian σ=0.01 | 测距噪声标准差 |


### 验证清单

| 检查项 | 预期 | 验证方法 |
|--------|------|---------|
| 机器人落地 | 不穿透地面 | Gazebo 中观察 |
| 轮子可旋转 | 左右轮独立旋转 | `ros2 topic echo /joint_states` |
| LiDAR 有数据 | /scan 话题有 LaserScan | `ros2 topic echo /scan` |
| 里程计输出 | /odom 话题有 Odometry | `ros2 topic echo /odom` |
| 速度控制 | 发布 /cmd_vel 机器人移动 | `ros2 topic pub /cmd_vel ...` |
