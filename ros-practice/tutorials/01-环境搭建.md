# 01 环境搭建：Ubuntu 24.04 + ROS2 Jazzy + Gazebo

## 1.1 Ubuntu 24.04 安装

### 安装方式选择

| 方式 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| U盘双系统 | 日常开发 | 性能最佳 | 需分区，有引导风险 |
| 虚拟机(VMware/VirtualBox) | 初学体验 | 隔离安全，快照方便 | GPU 加速受限，Gazebo 卡顿 |
| WSL2 | Windows 用户 | 轻量，文件互通 | GUI 需额外配置 |

### WSL2 安装（推荐 Windows 用户）

```powershell
# 在 Windows PowerShell（管理员）中执行
wsl --install -d Ubuntu-24.04
wsl --set-version Ubuntu-24.04 2
```

### WSL2 GUI 支持（Wslg）

WSL2 内置 Wslg 图形支持，可直接运行 Gazebo 和 RViz2：

```bash
# 验证 GUI 支持
sudo apt update && sudo apt install -y x11-apps
xeyes  # 弹出窗口即成功
```

## 1.2 ROS2 Jazzy 安装

### 添加 ROS2 软件源

```bash
# 安装依赖
sudo apt update && sudo apt install -y software-properties-common curl gnupg lsb-release

# 添加 ROS2 GPG 密钥
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg

# 添加软件源
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
  http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

sudo apt update
```

### 安装 ROS2 桌面完整版

```bash
# 完整版（含 Gazebo Harmonic、RViz2、示例包）
sudo apt install -y ros-jazzy-desktop-full

# 验证安装
source /opt/ros/jazzy/setup.bash
ros2 --version
# 输出: ros2 0.34.1 (jazzy)
```

> **注意**：Jazzy 版本自带 Gazebo 8.x (Harmonic)，与之前 Garden/Edifice 版本差异较大，命令为 `gz sim` 而非 `gazebo`。

### 配置环境变量

```bash
# 写入 ~/.bashrc 自动 source
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
source ~/.bashrc

# 验证 DDS 中间件
ros2 topic list  # 应输出空列表无报错
```

## 1.3 Nav2 导航栈安装

```bash
# Nav2 核心包
sudo apt install -y \
  ros-jazzy-navigation2 \
  ros-jazzy-nav2-bringup \
  ros-jazzy-nav2-minimal-tb4* \
  ros-jazzy-turtlebot4-gazebo

# SLAM 工具
sudo apt install -y \
  ros-jazzy-slam-toolbox \
  ros-jazzy-nav2-map-server

# 验证
ros2 pkg list | grep nav2  # 应列出 30+ 个 nav2 包
```

## 1.4 开发工具安装

```bash
# 编译工具
sudo apt install -y \
  python3-colcon-common-extensions \
  python3-rosdep \
  python3-vcstool \
  git

# 初始化 rosdep（首次使用）
sudo rosdep init
rosdep update

# Gazebo 插件开发库
sudo apt install -y \
  libgz-sim8-dev \
  ros-jazzy-ros-gz

# 可选： terminator 分屏终端
sudo apt install -y terminator
```

## 1.5 创建工作空间

```bash
# 创建 ROS2 工作空间
mkdir -p ~/ros2_ws/src && cd ~/ros2_ws

# 编译空工作空间（验证环境）
colcon build --symlink-install

# source 工作空间
source install/setup.bash

echo "source ~/ros2_ws/install/setup.bash" >> ~/.bashrc
```

## 1.6 环境验证清单

| 检查项 | 命令 | 预期结果 |
|--------|------|---------|
| ROS2 版本 | `ros2 --version` | ros2 0.34.x (jazzy) |
| DDS 中间件 | `echo $RMW_IMPLEMENTATION` | rmw_fastrtps_cpp |
| Gazebo 版本 | `gz sim --version` | 8.x |
| Nav2 包数 | `ros2 pkg list \| grep nav2 \| wc -l` | >30 |
| RViz2 | `rviz2` | 弹出空 RViz 窗口 |
| colcon | `colcon version-check` | 无报错 |

## 1.7 常见问题排查

### Q1: WSL2 下 Gazebo 黑屏

```bash
# 方案1：设置 GPU 软件渲染
export LIBGL_ALWAYS_SOFTWARE=1
gz sim

# 方案2：使用 WSLg 的 D3D 后端
export MESA_D3D12_DEFAULT_ADAPTER_NAME=NVIDIA
gz sim
```

### Q2: rosdep init 失败

```bash
# 国内网络问题，使用镜像
sudo sed -i 's/raw.githubusercontent.com\/ros\/rosdistro\/master/gitee.com\/idlity\/rosdistro\/master/g' /usr/lib/python3/dist-packages/rosdistro/__init__.py
sudo rosdep init
rosdep update
```

### Q3: colcon build 时找不到包

```bash
# 确保 source 了 ROS2 环境
source /opt/ros/jazzy/setup.bash
# 确认 ROS_DISTRO 变量
echo $ROS_DISTRO  # 应输出 jazzy
```
