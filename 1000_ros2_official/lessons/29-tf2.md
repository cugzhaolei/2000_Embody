# 第 29 课 · tf2 教程 (tf2 with turtlesim)

> 对应鱼香ROS官方教程：[tf2教程](http://dev.ros2.fishros.com/doc/Tutorials/Tf2/Tf2-Main.html)

## 目标
用 tf2 广播/监听坐标变换，让 turtle2 自动去追 turtle1。

## 代码位置
```
dev_ws/src/learning_tf2_py/    (Python 实现)
dev_ws/src/learning_tf2_cpp/   (C++ 实现)
```

## 操作（Python 版）

```bash
source /opt/ros/foxy/setup.bash
sudo apt install -y ros-foxy-tf-transformations ros-foxy-turtle-tf2-py
cd ~/dev_ws
colcon build --packages-select learning_tf2_py
source install/setup.bash

# 终端 1：turtle1 广播 world→turtle1
ros2 run learning_tf2_py turtle_tf2_broadcaster --ros-args -p turtlename:=turtle1

# 终端 2：turtle2 广播 world→turtle2
ros2 run learning_tf2_py turtle_tf2_broadcaster --ros-args -p turtlename:=turtle2

# 终端 3：监听，驱动 turtle2 追 turtle1
ros2 run learning_tf2_py turtle_tf2_listener --ros-args -p target_frame:=turtle1

# 终端 4：让 turtle1 动起来
ros2 run turtlesim turtle_teleop_key
```

看到 turtle2 自动跟随 turtle1。

### 查看坐标树
```bash
ros2 run tf2_tools view_frames        # 生成 frames.pdf
ros2 run tf2_tools echo world turtle1 # 打印某时刻的变换
```

### 静态广播器（world→mystaticturtle）
```bash
ros2 run learning_tf2_py static_turtle_tf2_broadcaster mystaticturtle 1 2 3 0 0 0
```

### 添加帧（carrot1，让 turtle2 追一个偏移目标）
```bash
ros2 run learning_tf2_py fixed_frame_tf2_broadcaster
# 再把监听器的 target_frame 改成 carrot1
ros2 run learning_tf2_py turtle_tf2_listener --ros-args -p target_frame:=carrot1
```


## 核心 API
**广播（Publisher 侧）**
```python
TransformBroadcaster(self).sendTransform(TransformStamped)
```
**监听（Consumer 侧）**
```python
self.tf_buffer.lookup_transform(to_frame, from_frame, rclpy.time.Time())
```
C++ 用 `tf_buffer_->lookupTransform(to, from, tf2::TimePointZero)`（Foxy 用 `tf2::TimePointZero`）。

## 时间与 tf2
- Foxy 的 Python `lookup_transform` 第三个参数用 `rclpy.time.Time()`。
- 「时间穿梭」教程中把 `Time()` 换成过去时刻（如 `Time(seconds=2)`）即可查看历史变换。
- 学习更多：把监听器 `target_frame` 换成 `carrot1`，配合 `dynamic_frame_tf2_broadcaster` 观察动态帧。
